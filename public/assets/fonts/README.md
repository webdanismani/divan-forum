# Bundled font

The default style ships the Roboto variable font so that the forum makes no
third-party requests (no Google Fonts). Roboto is licensed under the SIL Open Font
License 1.1 — the licence text is in `LICENSE-Roboto.txt` and must stay next to the
font files when the software is redistributed.

| Files | Family | Source |
| --- | --- | --- |
| `roboto-latin.woff2`, `roboto-latin-ext.woff2` | Roboto (weights 100–900) | https://github.com/googlefonts/roboto-3-classic |

There is a `latin` and a `latin-ext` subset; the second one carries the Turkish
letters (ğ, ş, ı, İ). The subsets were taken from the Fontsource builds.
